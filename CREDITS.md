# Credits

All art, models, textures, faces, scenes and sounds in SpinBuddies are generated in code
(Three.js geometry, Canvas2D decals, WebAudio synthesis) and are original to this project.

No third-party models, textures, fonts or sound files are bundled.

| Asset | Source | Licence |
|---|---|---|
| Display font | System font stack (Android: Roboto / system UI) — no font file bundled | n/a |
| 3D characters, scenes, box | Procedural, this repo | MIT (repo licence) |
| Sounds | Synthesised at runtime with WebAudio, this repo | MIT (repo licence) |
